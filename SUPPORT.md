# Support

Use [Discord](https://discord.gg/fmYtxask98) for setup questions, troubleshooting, and project discussion. Build and installation instructions are in each repository's README.

Report reproducible bugs in the relevant issue tracker:

- [Server](https://github.com/PhonoliteOrg/phonolite-server/issues)
- [App](https://github.com/PhonoliteOrg/phonolite-app/issues)

Include your version, operating system, steps to reproduce, and relevant error messages. Remove credentials and personal information from anything you share.

For suspected vulnerabilities, follow [SECURITY.md](https://github.com/PhonoliteOrg/.github/blob/main/SECURITY.md).
