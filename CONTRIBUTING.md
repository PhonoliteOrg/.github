# Contributing

Report bugs and propose changes in the relevant [Phonolite repository](https://github.com/orgs/PhonoliteOrg/repositories). Check existing issues first. For bugs, include the version, operating system, steps to reproduce, and expected and actual behavior. Remove passwords, tokens, and personal information from logs and screenshots.

Discuss broad changes in an issue before starting work. Keep pull requests focused, explain what changed and why, and include any checks you performed. Add or update documentation and tests where the change needs them.

Follow the repository's own instructions and license. Its README describes the build requirements and available checks. Documentation fixes and reproducible bug reports are useful contributions too.

For setup questions, use [Discord](https://discord.gg/fmYtxask98). Report security problems privately as described in [SECURITY.md](https://github.com/PhonoliteOrg/.github/blob/main/SECURITY.md).
