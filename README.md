# Phonolite community files

[Phonolite](https://github.com/PhonoliteOrg) is free, open-source software for
streaming a personal music library from a self-hosted server.

This repository contains the [organization profile](profile/README.md) and shared
guidance for the project:

- [Contributing](CONTRIBUTING.md)
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Security reports](SECURITY.md)
- [Getting help](SUPPORT.md)

GitHub uses these community files and issue and pull request templates as defaults
for Phonolite repositories that do not provide their own. Licenses are specified
in each project's repository.
