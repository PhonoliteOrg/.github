# Security

Report suspected vulnerabilities privately to [akuremek@telolith.com](mailto:akuremek@telolith.com). Do not open a public issue with exploit details.

Include the affected repository and version, a description of the problem, steps to reproduce, and the likely impact. Use a minimal example where possible. Do not send passwords, access tokens, private keys, or other people's data. Remove secrets from logs and screenshots.

Please coordinate public disclosure with the maintainers so a fix can be prepared. A repository's own security policy takes precedence over this default.
